# Portfolio Landing - Sofi

## Qué es
Landing page personal hecha con React y Tailwind, mostrando mis skills como developer junior en camino de aprendizaje.

## Cómo correrlo
npm install
npm run dev

## Uso de IA
- Herramienta que usé: Claude (chat).
- Qué generé con IA: principalmente el diseño con Tailwind (colores, espaciados, layout de las secciones).
- Qué hice a mano: creé las carpetas y los archivos de cada componente (ProfileHeader, Footer, SkillCard, SkillList), usando el snippet `rafce` para generar la estructura de arrow function de cada uno. 
También corregí colores y textos para que combinen entre secciones, ajusté el tamaño y la decoración de la imagen del header, y cambié la lógica del botón de contacto para que muestre mi link de GitHub.

## Lo que me costó
Al principio no entendía por qué el footer se veía "desconectado" del resto de la landing (colores y bordes distintos); aprendí a fijarme en que todas las secciones compartan la misma paleta y el mismo `max-w-7xl mx-auto px-6 md:px-10` para que quede alineado.
